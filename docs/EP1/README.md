- **Requerimientos en la rama `frontend`:** el enunciado pide explícitamente que la
  documentación de requerimientos esté incorporada en un Markdown de esa rama, por lo que
  el `README.md` de `frontend` mantiene las tablas de RF y RNF.
- **Código:** rama `frontend` (`src/pages`, `src/components`, `src/routes`, `src/services`).
